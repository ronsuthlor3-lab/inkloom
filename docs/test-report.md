## บั๊กที่พบและแก้แล้ว
1. **ระยะบรรทัดเรียกตัวเองวนไม่รู้จบ** เมื่อช่วงที่เลือกค้างเป็นของเก่า — สาเหตุ `Object.assign` คัดลอกค่าแทนตัวอ่าน/เขียน `lastRange` → ใช้ `defineProperty`, เลิกเรียกซ้ำ และอ่านช่วงที่เลือกจริงก่อน
2. **คำสั่งต่อเนื่อง (หนา → สี → ขนาด) ไปลงที่ช่วงเก่า** → ทุกคำสั่งจำช่วงที่เลือกใหม่ทันทีหลังทำงาน

## มือถือ / การเข้าถึง
- 375 px: ไม่มีแถบเลื่อนแนวนอน กระดาษย่อขอบให้พอดีจอ แถบเครื่องมือเลื่อนแนวนอน
- ปุ่มทุกปุ่มมีชื่อ (aria-label/ข้อความ) กรอบโฟกัสชัด; ปุ่มไม่แย่งโฟกัสจากเอกสาร; แป้นลัดมาตรฐาน + Ctrl+K ลิงก์, Ctrl+Enter แบ่งหน้า, Ctrl+H ค้นหา/แทนที่, Tab ในรายการ = เยื้อง, Tab ในตาราง = ช่องถัดไป

## ยังไม่ได้ทดสอบ
- Firefox / Safari, จอสัมผัสจริง
- เปิดไฟล์ .docx ที่บันทึกจาก Inkloom ใน Microsoft Word / WPS / LibreOffice จริง (ตรวจโครงสร้าง XML และเปิดกลับด้วย mammoth เท่านั้น)
- ไฟล์ .docx ซับซ้อนจากผู้ใช้จริง, การพิมพ์ออกกระดาษ/PDF
