# ความเป็นไปได้

| ฟีเจอร์ | ประเภท | หมายเหตุ |
|---|---|---|
| พิมพ์และจัดรูปแบบ (F-01 – F-11) | เบราว์เซอร์ล้วน | `contenteditable` ของเบราว์เซอร์ + คำสั่งจัดรูปแบบ + โค้ดเขียนเองสำหรับตาราง ขนาดอักษร ระยะบรรทัด |
| นับคำไทย (F-10) | เบราว์เซอร์ล้วน | `Intl.Segmenter('th', { granularity: 'word' })` |
| เปิด .docx (F-20) | เบราว์เซอร์ล้วน + ไลบรารี | mammoth 1.8.0 (BSD-2-Clause) — แปลงเป็น HTML เชิงความหมาย จึง **ไม่ได้** สี ขนาด แบบอักษร การจัดแนว |
| บันทึก .docx (F-21) | เบราว์เซอร์ล้วน + ไลบรารี | docx 8.5.0 (MIT) — แปลง HTML → โครงสร้าง docx เอง |
| PDF (F-23) | เบราว์เซอร์ล้วน | หน้าต่างพิมพ์ + CSS `@page` |
| HTML / TXT / MD, บันทึกอัตโนมัติ | เบราว์เซอร์ล้วน | ตัวแปลง Markdown เขียนเอง (ส่วนพื้นฐาน) |
| แบ่งหน้าจริงขณะแก้ไข | เบราว์เซอร์ล้วน (ยากมาก) | ภายหลัง; ตอนนี้แสดงเส้นบอกขอบหน้าโดยประมาณ และแบ่งหน้าจริงตอนพิมพ์ |
| track changes, ความคิดเห็น, หัว/ท้ายกระดาษ, สารบัญ | เบราว์เซอร์ล้วน | ภายหลัง |
| เปิด .doc เก่า | ทำไม่ได้ในเบราว์เซอร์อย่างดี | แนะนำให้บันทึกเป็น .docx ก่อน |
| ทำงานร่วมกัน | ต้องมีเซิร์ฟเวอร์ | ภายหลัง |
| ถอดโค้ด / ใช้ไฟล์ของ WPS | ทำไม่ได้/ไม่ควรทำ | ม.30 |

## MVP vs ภายหลัง
- **MVP**: F-01 – F-26
- **ภายหลัง**: แบ่งหน้าจริง, หัว/ท้ายกระดาษ, สารบัญ, เชิงอรรถ, ความคิดเห็น, track changes, ขอบกระดาษปรับได้, แนวนอน

## ความเสี่ยง
- `document.execCommand` ถูกระบุว่าเลิกพัฒนาแล้ว แต่ทุกเบราว์เซอร์หลักยังรองรับ — แยกโค้ดเรียกไว้ที่เดียว เปลี่ยนภายหลังได้
- เปิด .docx แล้วบันทึกกลับ: รูปแบบที่ mammoth ไม่อ่าน (สี ขนาด แบบอักษร หัว/ท้ายกระดาษ) หาย → แจ้งเมื่อเปิดไฟล์
- ไลบรารี .docx ใหญ่ (~1.4 MB รวม) → โหลดเฉพาะตอนเปิด/บันทึก .docx
