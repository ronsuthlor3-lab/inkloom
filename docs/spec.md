# สเปกเชิงหน้าที่ — Inkloom

> เขียนด้วยคำของเราเองจากความรู้ทั่วไปว่า "โปรแกรมพิมพ์เอกสาร" ทำอะไร
> ไม่ได้ถอดโค้ด ไม่ได้คัดลอกข้อความ ไอคอน หรือหน้าจอของโปรแกรมใด

## ผู้ใช้และเป้าหมาย
นักเรียน ครู พนักงาน ร้านค้า ที่ต้องพิมพ์ จัดรูปแบบ และ **เปิด/แก้/บันทึกไฟล์ .docx** หรือส่งออกเป็น PDF ในเบราว์เซอร์ โดยไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีบัญชี และไม่อัปโหลดไฟล์

## ฟีเจอร์และเกณฑ์ยอมรับ

### พิมพ์และจัดรูปแบบ
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-01 | หน้ากระดาษ | แสดงเป็นแผ่น A4 (กว้าง 21 ซม. ขอบ 2.54 ซม.) พร้อมเส้นบอกขอบหน้าโดยประมาณ และจำนวนหน้า |
| F-02 | ตัวอักษร | ตัวหนา เอียง ขีดเส้นใต้ ขีดฆ่า ตัวยก/ตัวห้อย, แบบอักษร (ไทยอย่างน้อย 3 แบบ), ขนาด 8–72 pt, สีตัวอักษร, สีไฮไลต์ |
| F-03 | ย่อหน้า | หัวเรื่อง 1–3, ปกติ, คำพูดอ้างอิง; จัดซ้าย/กลาง/ขวา/เต็มแนว; เยื้องเข้า/ออก; ระยะบรรทัด 1.0 / 1.15 / 1.5 / 2.0 |
| F-04 | รายการ | หัวข้อย่อย • และลำดับเลข ซ้อนระดับได้ด้วย Tab / Shift+Tab |
| F-05 | ตาราง | แทรกตาราง ก×ข, เพิ่ม/ลบ แถวและคอลัมน์จากช่องที่เคอร์เซอร์อยู่ |
| F-06 | แทรกอื่น ๆ | รูปภาพจากไฟล์ (ปรับความกว้าง), ลิงก์, เส้นคั่น, ตัวแบ่งหน้า, วันที่วันนี้ |
| F-07 | ล้างรูปแบบ | กลับเป็นข้อความธรรมดา |
| F-08 | ย้อนกลับ/ทำซ้ำ | Ctrl+Z / Ctrl+Y และปุ่ม |
| F-09 | ค้นหาและแทนที่ | ค้นหาถัดไป, แทนที่, แทนที่ทั้งหมด, ตรงตัวพิมพ์เล็ก/ใหญ่ได้ |
| F-10 | นับคำ | นับคำภาษาไทยด้วยตัวตัดคำของเบราว์เซอร์ (ไม่ใช่นับช่องว่าง), นับตัวอักษร |
| F-11 | วางจากที่อื่น | วางจากเว็บ/โปรแกรมอื่นแล้วเก็บรูปแบบพื้นฐาน ตัดสคริปต์และสิ่งอันตรายทิ้ง; Ctrl+Shift+V = วางเป็นข้อความล้วน |

### ไฟล์
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-20 | เปิด .docx | หัวเรื่อง ย่อหน้า ตัวหนา/เอียง/ขีดเส้นใต้ รายการ ตาราง รูปภาพ ลิงก์ |

| F-24 | บันทึกอัตโนมัติ | ปิดแล้วเปิดใหม่งานยังอยู่ |

| F-26 | ความเป็นส่วนตัว | ไม่ส่งไฟล์ออกจากเครื่อง |

## กรณีขอบ
เอกสารว่าง, เอกสารยาวหลายสิบหน้า, ข้อความไทยปนอังกฤษและอีโมจิ, รูปภาพใหญ่, ตารางซ้อนในตาราง, ไฟล์ .docx เสีย/ไม่ใช่ docx, ไฟล์ .doc แบบเก่า

## สิ่งที่ไม่ทำ (MVP)
ติดตามการแก้ไข (track changes), ความคิดเห็น, หัว/ท้ายกระดาษแก้ไขได้, เชิงอรรถ, สารบัญอัตโนมัติ, จดหมายเวียน, ตรวจคำผิด (ใช้ของเบราว์เซอร์), คอลัมน์, การแบ่งหน้าจริงขณะแก้ไข, ไฟล์ .doc แบบเก่า, ทำงานร่วมกัน
