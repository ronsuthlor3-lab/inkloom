# Inkloom

<img src="assets/logo.svg" width="64" alt="">

โปรแกรมพิมพ์เอกสารที่ทำงาน **ในเบราว์เซอร์ของคุณทั้งหมด** — เปิด แก้ไข บันทึก `.docx` ส่งออก PDF นับคำภาษาไทยได้ถูกต้อง ไม่มีไฟล์ถูกอัปโหลด ไม่ต้องติดตั้ง ไม่ต้องมีบัญชี

**ใช้งานออนไลน์:** https://ronsuthlor3-lab.github.io/inkloom/
ลองเปิดไฟล์ตัวอย่าง [`samples/report.docx`](samples/report.docx) (รายงานมีหัวเรื่อง ตาราง รูป รายการ ลิงก์ ตัวแบ่งหน้า)

| แทรก | ตาราง (เพิ่ม/ลบแถวและคอลัมน์), รูปภาพ (ปรับขนาด/จัดแนว, ลากวางหรือวางจากคลิปบอร์ด), ลิงก์, เส้นคั่น, ตัวแบ่งหน้า, วันที่ไทย |

### ปุ่มลัด
Ctrl+B/I/U ตัวหนา/เอียง/ขีดเส้นใต้ · Ctrl+Z/Y ย้อน/ทำซ้ำ · Ctrl+S บันทึก .docx · Ctrl+P พิมพ์/PDF · Ctrl+K ลิงก์ · Ctrl+H หรือ Ctrl+F ค้นหา/แทนที่ ·
Ctrl+Enter แบ่งหน้า · Ctrl+Shift+V วางเป็นข้อความล้วน · Tab ในรายการ = เยื้อง · Tab ในตาราง = ช่องถัดไป (ช่องสุดท้ายเพิ่มแถว) · Ctrl+คลิกลิงก์ = เปิด

## วิธีรันเอง
เปิดผ่านเซิร์ฟเวอร์ในเครื่องใดก็ได้ เช่น `python -m http.server` แล้วเข้า `http://localhost:8000`
ต้องต่ออินเทอร์เน็ตเพื่อโหลดแบบอักษร (Google Fonts) และไลบรารี .docx ตอนเปิด/บันทึก .docx ครั้งแรก

**สำรองข้อมูล:** บันทึกอัตโนมัติอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น — กด "บันทึก .docx" เป็นระยะ

## แรงบันดาลใจและความแตกต่าง
แนวคิด "โปรแกรมพิมพ์เอกสารใช้ง่ายที่เปิดไฟล์ Office ได้" ได้แรงบันดาลใจจาก WPS Writer ในชุด WPS Office (ใช้ชื่อเพื่ออ้างถึงเท่านั้น)

- โครงการนี้ **ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรองหรือสนับสนุน** จาก Kingsoft Office Software หรือเจ้าของ WPS Office; WPS เป็นเครื่องหมายของเจ้าของ ชื่ออื่นที่กล่าวถึงเป็นของเจ้าของแต่ละราย
- เขียนใหม่ทั้งหมดจากสเปกเชิงหน้าที่ของเราเอง ([docs/spec.md](docs/spec.md)) **ไม่ได้ถอดโค้ด** ไม่มีโค้ด ข้อความ ไอคอน หน้าจอ แม่แบบ หรือไฟล์ใด ๆ ของ WPS

| | Inkloom | WPS Writer (ตามที่ทราบทั่วไป) |
|---|---|---|
| ชื่อ / โลโก้ / สี | Inkloom, ปลายปากกาบนกระดาษ, ม่วงพลัม + อำพัน | ของเจ้าของ |
| ที่รัน | เบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องมีบัญชี | โปรแกรมเดสก์ท็อป/มือถือ/บริการของเจ้าของ |
| การแบ่งหน้า | แสดงเส้นบอกขอบหน้าโดยประมาณ แบ่งหน้าจริงตอนพิมพ์/PDF | แบ่งหน้าจริงขณะแก้ไข |
| ไม่มีใน Inkloom | ติดตามการแก้ไข, ความคิดเห็น, หัว/ท้ายกระดาษแก้ไขได้, เชิงอรรถ, สารบัญ, จดหมายเวียน, คอลัมน์, แม่แบบ, ทำงานร่วมกัน | — |
| สัญญาอนุญาต | MIT โอเพนซอร์ส | ซอฟต์แวร์ของเจ้าของ |

## ข้อจำกัดที่ทราบ
- **เปิด .docx:** ได้หัวเรื่อง ย่อหน้า ตัวหนา/เอียง/ขีดเส้นใต้ รายการ ตาราง รูป ลิงก์ แต่ **ไม่ได้** สี ขนาด แบบอักษร การจัดแนว หัว/ท้ายกระดาษ (ข้อจำกัดของ mammoth)
- **บันทึก .docx:** ใช้แบบอักษร Sarabun เป็นค่าเริ่มต้น — ถ้าเครื่องที่เปิดไม่มี โปรแกรมจะใช้แบบอักษรแทน
- ไม่เปิดไฟล์ `.doc` แบบเก่า (บันทึกเป็น .docx ก่อน)
- การแบ่งหน้าขณะแก้ไขเป็นค่าประมาณ; จำนวนหน้าจริงดูได้ตอนพิมพ์/PDF
- ค้นหาไม่เจอคำที่ถูกแบ่งด้วยรูปแบบต่างกันกลางคำ (เช่น ครึ่งคำตัวหนา)
- ใช้ `document.execCommand` ของเบราว์เซอร์ (ยังรองรับในเบราว์เซอร์หลัก แต่ถูกระบุว่าเลิกพัฒนาแล้ว)
- ทดสอบแล้วบน Chromium; Firefox/Safari และการเปิดใน Word/WPS/LibreOffice จริงยังไม่ได้ทดสอบ (ดู [docs/test-report.md](docs/test-report.md))

### แผนภายหลัง
แบ่งหน้าจริงขณะแก้ไข, หัว/ท้ายกระดาษ, สารบัญอัตโนมัติ, เชิงอรรถ, ความคิดเห็น, ติดตามการแก้ไข, ขอบกระดาษ/แนวนอน, นำเข้าสีและขนาดจาก .docx
